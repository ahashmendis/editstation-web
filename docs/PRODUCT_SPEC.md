# Product Spec

Derived from KB §3.2–3.3, §4, §9, §16.

## Roles (MVP)

- **Admin**: everything operational. Future roles (team manager, QC reviewer, finance assistant)
  are not built until a real need emerges.
- **Editor**: vetted freelancer; sees only their own records and projects made available/assigned.

## Brief types (all required from release 1)

1. **Fully instructed**: footage, script/sequence plan, detailed instructions, supplied music/sound,
   graphics/fonts/brand guidelines, export specs, deadline, compensation.
2. **Reference-based**: footage plus one or more references. Each reference: title, URL, optional
   file/excerpt, start/end timecodes or timestamp, what to observe, priority (essential/optional),
   category (pacing, transitions, colour, typography, storytelling, framing, sound design, motion
   graphics), access/permission notes. May require an editor interpretation before work.
3. **Creative-led**: outcome and audience, core message, brand/visual constraints, mandatory
   content, prohibited content, deliverables/specs, deadline, compensation.

Brief type may affect complexity but must not automatically set the rate.

## Admin dashboard

Overview · Projects · Editors & applications · Assignments · Negotiations · Submissions ·
Revisions · Payments · Basic analytics · Settings & audit history.

Capabilities: create/edit/archive projects; choose brief type; add instructions, assets,
references; set proposed pay and deadline; approve/reject editors; invite/assign/reassign;
review counteroffers; confirm agreed pay; review submissions; request revisions or approve; track
and mark payment status; view activity history.

## Editor dashboard

Profile · Application status · Eligible projects · Invitations · Active assignments · Brief &
assets · Reference library · Interpretation / brief confirmation · Submission history · Revision
feedback · Earnings & payment history.

Capabilities: apply and update permitted profile fields; view only eligible projects and own
assignments; accept/decline/counteroffer; ask questions via the project's communication mechanism
(see OPEN_QUESTIONS); confirm brief and pay; submit work and revisions; view own payments.

## Excluded from MVP

Client portal/accounts · public marketplace · open bidding · automated matching · payment gateway ·
live collaborative editing · AI video editing · complex chat · automated tax/accounting ·
multi-editor teams on one project (unless the pilot proves it necessary).
